# SpoolmanDB Workspace Rules

- **SpoolmanDB-Community vs SpoolmanDB:**
  - `SpoolmanDB-Community` (https://github.com/Icezaza2543/SpoolmanDB-Community) and `SpoolmanDB` (https://github.com/Icezaza2543/SpoolmanDB) are completely different and separate repositories.
  - They are NOT the same repository, even though they both fork/derive from `Donkie/SpoolmanDB`.
  - Git operations (pushes, pull requests, merges, and branches) must be performed and managed separately for each repository.
